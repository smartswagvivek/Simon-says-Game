

# 🎮 Simon Says Game Overview

The Simon Says Game is a web-based application designed to test and enhance your memory through a fun and interactive gameplay experience. Players must replicate a sequence of button flashes generated by the game, improving their recall abilities as they advance through levels.

## 🛠️ Setup Instructions

Follow these steps to get started:

1. **Clone the repository to your local machine:**
   ```bash
   git clone https://github.com/smartswagvivek/Simon-says-Game.git
   cd Simon-says-Game
   ```

2. **Open the `index.html` file in your preferred web browser.**  
   No additional installations or configurations are required since this is a static web application.

## 🚀 Usage

- **Start the Game:** Press any key on your keyboard to begin.
- **Follow the Sequence:** Observe the colored buttons as they flash in a specific order.
- **Input Your Response:** Click on the buttons in the same order as they appeared. Your clicks will flash the buttons green if you are correct.
- **Game Over:** If you make a mistake, your score will be displayed, and you can press any key to play again.
  
## 🧰 Technologies Used

- **HTML**: Structure of the game interface.
- **CSS**: Styling for buttons and layout.
- **JavaScript**: Game logic, including sequence generation and user input handling.
